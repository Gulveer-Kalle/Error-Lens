Authentication

Most endpoints require a JWT token in the request headers.

The token can be copied securely from the Settings page once you are signed in.

Authorization: Bearer <token>

Endpoints

POST /auth/register

Register a new user.

Request Body:

{{ '{' }}
  "email": "string (required)",
  "password": "string (required)"
{{ '}' }}

POST /auth/login

Login and receive a JWT token.

Request Body:

{{ '{' }}
  "email": "string (required)",
  "password": "string (required)"
{{ '}' }}

Response:

{{ '{' }}
  "token": "string"
{{ '}' }}

POST /events

Submit a new error or event for the authenticated user.

Requires: Authorization: Bearer <token>

Request Body:

{{ '{' }}
  "application": "string (required)",
  "message": "string (required)",
  "severity": "low|medium|high|critical (required)",
  "environment": "development|staging|production (required)",
  "event_type": "error|warning|info (optional, default: error)",
  "source": "string (optional, default: unknown)"
{{ '}' }}

GET /events

Fetch events scoped to the authenticated user.

Requires: Authorization: Bearer <token>

Query Parameters:

  • severity - Filter by severity (optional)
  • environment - Filter by environment (optional)

Example:

/events?severity=critical&environment=production

Get aggregated statistics about events for the authenticated user.
